Entry for the make.fun bounty
[Rename the Planet](https://make.fun/c/u-motasimfuad-rename-the-planet-094b0369):
one line under 200 characters that gives a planet of our solar system
a funny new name and says why in the same breath.

`main.py` writes the submitted line to `/output/entry.txt`. It is
deterministic, uses only the Python standard library, and needs no
network. `CANDIDATES.md` records the candidate lines and the local
judging that picked the winner.

Run it with:

```sh
python3 main.py
```
